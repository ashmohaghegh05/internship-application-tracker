# Layout Plan

## Five-Second Goal

When I open the Internship Application Tracker, I want to immediately understand:

- how many applications I have
- how many are still active
- how many interviews and offers I have
- which applications need follow-up

The application progress should be more noticeable than the form or decorative elements.

## Layout Options I Considered

### Option A — Form First

1. Project name and short introduction
2. Add Application form
3. Progress summary
4. Status filter
5. Application list
6. Reset control

I did not choose this layout because the form would appear before the information the tool is supposed to calculate for me.

### Option B — Progress First

1. Project name and short introduction
2. Progress summary
3. Add Application form
4. Status filter
5. Application list
6. Reset control

I liked this structure because I can understand my internship search before entering or changing information.

### Option C — Split Workspace

Desktop:

- Progress summary near the top
- Add Application form on the left
- Application record on the right
- Filter beside the application record
- Reset control at the bottom

Mobile:

1. Introduction
2. Progress summary
3. Add Application form
4. Filter
5. Application records
6. Reset control

This gives the tool more of a dashboard/workspace feeling.

## Chosen Layout

I chose a combination of the **Progress First** and **Split Workspace** layouts.

### Top of the Page

The page begins with:

1. Internship Application Tracker label
2. Large headline
3. Short explanation
4. Total number of applications

The headline explains the purpose of the tool, while the application count gives the user an immediate answer.

### Progress Summary

The next section shows:

- Total Applications
- Active Applications
- Interviews
- Offers
- Follow-Ups

This comes before the form because the calculated progress is the most important information on the page.

### Main Workspace

On desktop, the main workspace uses two columns.

#### Left Column

The Add Application form contains:

- Company
- Role
- Date applied
- Status
- Notes
- Follow-up checkbox
- Add Application button

#### Right Column

The Application Record contains:

- Filter control
- Saved applications
- Company and role
- Date applied
- Notes
- Follow-up control
- Editable status
- Delete action

The Application Record receives slightly more space because reviewing existing applications is more important than entering a new one.

### Bottom of the Page

The Reset All action appears at the bottom.

It is intentionally separated from the main actions because it deletes all saved tracker data.

## Mobile Layout

On a phone, everything changes to one column.

The order is:

1. Header
2. Introduction
3. Application total
4. Progress summary
5. Add Application form
6. Filter
7. Application records
8. Reset All
9. Footer

The progress summary remains above the form so the user can understand their current position before entering new information.

## Visual Priority

The visual hierarchy should be:

1. Progress and calculated numbers
2. Application records
3. Form actions
4. Supporting text
5. Reset and destructive actions

## Design Rule

The application progress is the answer, so nothing decorative should compete with the summary numbers or application information.
